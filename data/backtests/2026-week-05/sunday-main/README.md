# NFL 2026 Week 5 — Sunday main slate

Keep every artifact from the Sunday main slate in this folder so it remains
separate from the Week 5 Showdown review.

- `salary-files/`: the original DraftKings and FanDuel salary CSVs.
- `generated-lineups/`: every optimizer export, including runs that were not entered.
- `entered-lineups/`: the final rosters that were actually submitted.
- `results/`: final contest standings CSV or ZIP exports.

Use descriptive names when possible, such as `draftkings-classic-final.csv` or
`fanduel-main-standings.zip`. Do not overwrite earlier generated runs; their
timestamps and differences are useful for auditing projection changes.
