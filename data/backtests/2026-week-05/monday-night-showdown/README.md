# NFL 2026 Week 5 — Monday night Showdown

Keep every artifact from the Monday-night single-game slate in this folder.

- `run-archives/`: complete optimizer run ZIPs for DraftKings and FanDuel.
- `salary-files/`: original platform salary CSVs, if they are not already
  contained in the run archives.
- `entered-lineups/`: final rosters actually submitted, when available.
- `results/`: final contest standings CSV or ZIP exports.

Do not rename or overwrite the run ZIPs before review; their original names and
timestamps help identify which projections and settings were used.
